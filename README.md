# Taste the Joy 🤎 | متجر حلويات وكيك فاخر

مشروع متجر إلكتروني متكامل للحلويات والكيك الفاخر في الجزائر، مبني بواجهة أمامية حديثة باستخدام **React** وخلفية خادم قوية باستخدام **Node.js & Express** مع ربط كامل بقاعدة بيانات **PostgreSQL / Supabase** وفقًا للمخطط (Schema) المعطى بدقة.

---

## 🌟 مميزات المشروع

### 1. واجهة المستخدم للعملاء (Customer Experience - React)
- **هوية بصرية دافئة وأنيقة**: لوحة ألوان مستوحاة من المخبوزات والحلويات (البيستاشيو، الشوكولاتة، الكريمة، والبيج) مع خط *Tajawal* العربي ودعم RTL كامل.
- **تصفح حسب الأقسام والمناسبات**:
  - Cheesecake (بيستاشيو، شوكولا، سنيكرز، فراولة...).
  - Cakes (كيكات أعياد الميلاد والاحتفالات الفاخرة).
  - Crunchy Cake (كرانشي بوينو وبيستاشيو).
  - فلتر المناسبات (أعياد الميلاد، التخرج والنجاح، Valentine، الهدايا، والمناسبات الخاصة).
- **أداة تخصيص بوكس البراونيز التفاعلية (Brownies Box Customizer)**:
  - اختيار عدد الحبات (5، 6، 7، 8، 9، 10 حبات) مع تحديث فوري للسعر.
  - اختيار نوع صوص الشوكولاتة الذائبة (بيستاشيو إيطالي، شوكولاتة الحليب، بندق نوتيلا).
- **تفاصيل المنتج المتقدمة (Product Modal)**:
  - معرض صور متعددة للحلويات.
  - دعم مجموعات الخيارات من قاعدة البيانات (`product_option_groups` & `product_option_values`) مثل الحجم، نكهة السبونج، والإضافات مع احتساب فروق الأسعار (`price_delta`).
- **سلة مشتريات ديناميكية (Cart Drawer)**:
  - تعديل الكميات وحساب المجموع الفوري بالدينار الجزائري (دج / DZD).
  - خانة تطبيق كوبونات الخصم والتحقق منها مباشرة من الخادم (`coupons`).
- **إتمام الطلب (Checkout Modal)**:
  - التبديل بين التوصيل للمنزل (`delivery`) أو الاستلام من المحل (`pickup`).
  - قائمة كاملة لجميع **الولايات الجزائرية الـ 58**.
  - تحديد موعد وتاريخ التسليم أو الاحتفال (`scheduled_at`).
  - الدفع نقدًا عند الاستلام (Cash on delivery).
  - إنشاء الطلب مباشرة وتوليد رابط واتساب مع رسالة الطلب الكاملة للتأكيد الفوري!
- **تتبع الطلبات (Order Tracking)**:
  - إمكانية بحث العميل برقم طلبه لمتابعة مرحلته: جديد ➔ قيد المراجعة ➔ قيد التحضير ➔ جاهز ➔ مكتمل.
- **المفضلة (Favorites)**:
  - حفظ الحلويات المفضلة لكل عميل برقم تعريف فريد (`guest_id`).
- **تقييمات وآراء العملاء (Reviews)**:
  - عرض التقييمات المقبولة بالنجوم والتعليقات.
  - نموذج إضافة تقييم جديد مع نظام انتظار الموافقة من الإدارة.

---

### 2. لوحة تحكم الإدارة (Admin Dashboard)
- **تسجيل دخول آمن بواسطة JWT**:
  - بيانات الدخول الافتراضية: `admin` / `admin123`.
- **نظرة عامة وإحصائيات مباشرة (KPIs)**:
  - إجمالي المبيعات بالدينار الجزائري.
  - إجمالي عدد الطلبات والطلبات الجديدة التي بانتظار المراجعة.
  - عدد التقييمات المعلقة.
- **إدارة الطلبات (Orders Management)**:
  - عرض تفاصيل كل طلب، اسم الزبون، الولاية، العنوان، المنتجات والملاحظات.
  - تغيير حالة الطلب بنقرة واحدة (`new`, `reviewing`, `preparing`, `ready`, `completed`, `cancelled`).
  - زر مراسلة الزبون مباشرة على WhatsApp.
- **إدارة المنتجات (Products Management)**:
  - إضافة منتجات جديدة أو تعديل الأسعار، الصور، الأقسام، وشارات العرض (الأكثر طلبًا / وصل حديثًا).
- **إدارة كوبونات الخصم (Coupons Management)**:
  - إنشاء كوبونات بنسبة مئوية أو مبلغ ثابت، مع تحديد حد أدنى للطلب وحد أقصى للاستخدام.
- **مراجعة التقييمات (Reviews Moderation)**:
  - قبول ونشر التقييمات الإيجابية أو رفضها وحذفها.
- **إعدادات المتجر (Store Settings)**:
  - تعديل رقم WhatsApp، حساب Instagram، سعر التوصيل، ونبذة "من نحن".

## 🗄️ هيكل قاعدة البيانات (Database Schema)

المشروع مبني ليعمل مباشرة مع **PostgreSQL / Supabase** وفقًا للجداول التالية:

```sql
- public.admin_users            -- مسؤولو لوحة التحكم
- public.categories             -- أقسام الحلويات (JSONB للأسماء والأوصاف)
- public.products               -- المنتجات والأسعار والخيارات
- public.product_option_groups  -- مجموعات الخيارات (الحجم، النكهة...)
- public.product_option_values  -- قيم الخيارات مع فروق الأسعار (price_delta)
- public.coupons                -- كوبونات الخصم والشروط
- public.orders                 -- الطلبات، طريقة الاستلام، والولايات
- public.order_items            -- بنود كل طلب ومواصفاتها
- public.favorites              -- المفضلة المرتبطة بالـ guest_id
- public.reviews                -- تقييمات العملاء وحالة اعتمادها
- public.settings               -- إعدادات المتجر وأرقام التواصل
```

> 💡 **ميزة التشغيل الفوري الذكي**: في حال لم تقم بإدخال رابط قاعدة البيانات بعد، يمتلك الخادم **مخزن ذاكرة ذكي مدمج (In-Memory Mock Store)** مُحمّل بكافة البيانات التجريبية، مما يسمح بتشغيل وتجربة كامل وظائف المتجر والـ Backend فورًا دون أي إعداد مسبق! وبمجرد وضع رابط `DATABASE_URL` في ملف `.env`، يتحول تلقائيًا إلى PostgreSQL/Supabase وينشئ الجداول ويزرع البيانات.

## 🚀 طريقة تشغيل المشروع محليًا

### المتطلبات:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### الخطوة 1: تشغيل الـ Backend
```bash
cd backend
npm install
node server.js
```
سيعمل الخادم على: `http://localhost:5000`

### الخطوة 2: تشغيل الـ Frontend (React)
في نافذة موجه أوامر جديدة:
```bash
cd frontend
npm install
npm run dev
```
ستفتح واجهة المتجر على: `http://localhost:3000`

> 💡 لمستخدمي ويندوز: يمكنك أيضًا النقر المزدوج على ملف `start-dev.bat` لتشغيل كل من الخادم والواجهة معًا بنقرة واحدة!

## 🔗 ربط قاعدة بيانات Supabase / PostgreSQL الحقيقية

1. أنشئ مشروعًا جديدًا على [Supabase](https://supabase.com).
2. افتح ملف `backend/.env` وأضف رابط الاتصال:
```env
PORT=5000
DATABASE_URL=postgresql://postgres.[YOUR-REF]:[YOUR-PASSWORD]@aws-0-[YOUR-REGION].pooler.supabase.com:6543/postgres
DB_SSL=true
```
3. عند إعادة تشغيل الخادم (`node server.js`)، سيقوم تلقائيًا بالاتصال بقاعدة بياناتك وتشغيل استعلامات التهيئة وزرع البيانات الأولية لتبدأ العمل بها فورًا!

## 🔌 نقاط النهاية الأساسية للـ API (REST Endpoints)

| المسار | الطريقة | الوصف |
|--------|---------|-------|
| `/api/products` | GET / POST | جلب قائمة الحلويات أو إضافة حلوى جديدة (للمسؤول) |
| `/api/products/:idOrSlug` | GET / PUT / DELETE | جلب أو تعديل أو حذف منتج |
| `/api/categories` | GET / POST / PUT | إدارة أقسام الحلويات |
| `/api/orders` | POST / GET | إنشاء طلب جديد للزبون أو استعراض الطلبات (للمسؤول) |
| `/api/orders/:idOrNum` | GET | تتبع حالة طلب محدد |
| `/api/orders/:id/status` | PATCH | تغيير حالة الطلب |
| `/api/coupons/validate` | POST | التحقق من صلاحية كوبون وحساب الخصم |
| `/api/reviews` | GET / POST | استعراض التقييمات أو إرسال تقييم جديد |
| `/api/reviews/:id/status` | PATCH | قبول أو رفض تقييم معلق |
| `/api/favorites` | GET / POST | إدارة المفضلة للزبائن |
| `/api/admin/login` | POST | تسجيل دخول الإدارة والحصول على توكن JWT |
| `/api/admin/stats` | GET | استرجاع إحصائيات المبيعات والأرباح |
